# quester.club

**quester → querent → quantum** — a passive Helmholtz field experience of what quantum would feel like. A PQRS / Querent public showcase.

Every screen runs by itself. When the page opens, the browser draws 256 bits from `crypto.getRandomValues`, hashes them with SHA-256, and uses that key to place every vortex, source and wave phase. The key never leaves the device, so each viewer sees a field nobody else will see.

| Screen | Field |
|---|---|
| Hero | Full Helmholtz flow: F = ∇φ + ∇×ψ |
| 01 Superposition | Weight drifts between the irrotational (∇φ) and solenoidal (∇×ψ) parts |
| 02 Interference | Complex-amplitude sum of keyed point sources, colored by phase |
| 03 Entanglement | Mirrored pairs with opposite curl |
| 04 Uncertainty | σx · σp held at a floor |
| 05 Measurement | Free flow → collapse to one point → re-opening |
| 06 Your key | The 256-bit session key as a bit grid |

**Drift** auto-advances every 18 s for kiosk / TV display and pauses for 45 s on any touch, scroll or key. It is off when the viewer has reduced motion turned on.

## Hosting

- GitHub Pages from `main` / root, custom domain in `CNAME`.
- DNS records are in `quester.club.zone` (GoDaddy import).
